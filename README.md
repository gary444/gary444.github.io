# Portfolio of Gareth Rendle

##  How to run locally

  * navigate to root
  * `npm run dev`

The web app will be accessible with the given localhost address, i.e. http://localhost:XXXX/

Changes will be reflected in the locally accessed version without further steps.

## How to deploy

 * Set up Firebase (once only):
   * `firebase login`
   * Works with cmd, but not powershell

 * Build a runnable file: `npm run build`
 * Deploy to Firebase: `firebase deploy` (assuming firebase is setup)
